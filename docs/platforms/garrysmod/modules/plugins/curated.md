# Curated Plugins
A list of known plugins that have been made for everyone to enjoy.


## BSA Public Plugins
[Plugins - Public](https://github.com/Buildstruct/bsa-plugin-gmod)\
- A collection of plugins by contributors of BSA.

- [logging](https://github.com/Buildstruct/bsa-plugin-gmod/tree/develop/lua/bsa/plugins/logging) - A collection of basic logging utilities for sandbox.
- [limits.lua](https://github.com/Buildstruct/bsa-plugin-gmod/tree/develop/lua/bsa/plugins/limits.lua) - Dynamic scanning & restrictions for sandbox-based limits.
- [noclip.lua](https://github.com/Buildstruct/bsa-plugin-gmod/tree/develop/lua/bsa/plugins/noclip.lua) - A basic noclip control addition for gamemodes.
- [physgun.lua](https://github.com/Buildstruct/bsa-plugin-gmod/tree/develop/lua/bsa/plugins/physgun.lua) - A basic physgun control addition for gamemodes.
- [promote.lua](https://github.com/Buildstruct/bsa-plugin-gmod/tree/develop/lua/bsa/plugins/promote.lua) - Automated promotion system for secondary groups.
- [stools.lua](https://github.com/Buildstruct/bsa-plugin-gmod/tree/develop/lua/bsa/plugins/stools.lua) - Dynamic scanning & restrictions for sandbox-based tools.
- [teams.lua](https://github.com/Buildstruct/bsa-plugin-gmod/tree/develop/lua/bsa/plugins/teams.lua) - Dynamic team allocation based on groups with colors.
- [template.lua](https://github.com/Buildstruct/bsa-plugin-gmod/tree/develop/lua/bsa/plugins/template.lua) - Create, bundle & autorun commands.
- [whitelist.lua](https://github.com/Buildstruct/bsa-plugin-gmod/tree/develop/lua/bsa/plugins/whitelist.lua) - Block players from joining without permissions.
