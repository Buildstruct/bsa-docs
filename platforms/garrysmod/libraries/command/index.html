    SERVER Commands¶

    Runtime command tree system with pluggable interfaces, argument parsing/validation, permission hooks, and recursive group routing.

    Info

    See core/libraries/command.lua for the actual design implementation.

    Note

    This adds a dedicated & constructed table to BSA as Commands.

    Functions¶

    • commands:new(): commands.object
      Creates a command manager, registers baseline argument types, and initializes dispatchers.

    Manager Object¶

    • commands:phrase(key: string, ...): string
      Resolves text from manager.phrases and applies string.format when arguments are provided.

    • commands:argument(name: string, callback: function): commands.argument
      Registers/replaces an argument parser by name.

    • commands:handle(interface: commands.interface, entity?: any): commands.invoker
      Creates an invoker bound to interface + source entity/custom data.

    • commands:interface(name: string, struct?: table): commands.interface
      Creates an interface instance and optionally overrides methods with struct.

    • commands:add(name: string): commands.functional
      Adds/replaces a root-level functional command.

    • commands:remove(name: string)
      Removes a root-level command/group entry.

    • commands:group(name: string): commands.group
      Gets or creates a root-level command group.

    • commands:flatten(children?: table, out?: table): table
      Returns flattened ordered list of groups/commands recursively.

    • commands:transport(children?: table, out?: table): table
      Builds a serializable tree snapshot (name, aliases, args, desc, permissions, flattened flags).

    • commands:prefix(text: string, prefixes: string[]): string | false, string?
      Matches first prefix and returns (prefix, remainder) or false.

    • commands:find(...path: string): commands.functional | false
      Finds nested functional command by exact path segments.

    Manager Events¶

    • commands.permission(node: commands.group | commands.functional, permission: string)
      Fired when permissions are added through .permission(...).

    • commands.added(node: commands.group | commands.functional)
      Fired when command/group is created.

    • commands.removed(node: commands.group | commands.functional)
      Fired when command/group is removed.

    • commands.refreshed(old_node: commands.group | commands.functional, new_node: commands.group | commands.functional)
      Fired when a same-name node is replaced.

    • commands.invoked(command: commands.functional, invoker: commands.invoker, raw_args: string[], parsed_args: any[])
      Fired after argument validation succeeds and before callback execution.

    Hooks¶

    • BSA.Commands:invoked(command: commands.functional, invoker: commands.invoker, raw_args: string[], parsed_args: any[])
      Fired after argument validation succeeds and before callback execution.
      Useful if you need to log commands.

    Functional Command¶

    Created through group:command(...) or manager-level commands:add(...).

    • command:serveronly(state: boolean): self
      Blocks invocation from serverless interfaces when true.

    • command:playeronly(state: boolean): self
      Requires a valid invoker entity when true.

    • command:alias(...aliases: string): self

    • command:permission(...perms: string): self
    • command:permissions(): string[]
    • command:callback(cb?: function): self | function
    • command:condition(cb?: function(self, invoker, next: function(state: boolean, reason?: string))): self | function
    • command:description(text?: string): self | string
    • command:argument(type: string, flags?: table): self

    • command:arguments(): table[]

    • command:validate(invoker: commands.invoker, ...raw: string): boolean, any[] | string, string?
      Runs argument parsers declared in meta.arguments.
      Returns (true, parsedArgs) or (false, userError, criticalTraceback?).

    • command:invoke(invoker: commands.invoker, ...raw: string): boolean, string?, string?
      Executes player/server guards, validation, emits commands.invoked, then runs callback via xpcall.
      On parser/callback error returns (false, reason, critical?).

    • command:path(concat?: boolean): string[] | string

    • command:list(): table
    • command:phrase(...): string
    • command:throw(...)
    • command:reply(...)
    • command:rreply(...)
    • command:message(targets, ...)
    • command:rmessage(targets, ...)
      Proxy output helpers routed through active invoker/interface.

    Group¶

    Hierarchical command container.

    • group:group(name: string): commands.group
      Creates nested group.

    • group:category(name: string): commands.group
      Alias of group:group(...).

    • group:command(name: string): commands.functional
      Creates/replaces child command.

    • group:add(name: string): commands.functional
      Alias of group:command(...).

    • group:remove(name: string)
      Removes child command/group.

    • group:flattenize(): self
      Marks group as flattened alias scope for interface resolver.

    • group:alias(...aliases: string): self

    • group:permission(...perms: string): self
    • group:permissions(): string[]
    • group:condition(cb?: function(self, invoker, next: function(state: boolean, reason?: string))): self | function
    • group:description(text?: string): self | string
    • group:path(concat?: boolean): string[] | string
    • group:list(): table
    • group:phrase(...): string

    Interface¶

    Input adapter that parses a text message and routes to command tree.

    • interface:invoke(invoker: commands.invoker, message: string)
      Resolves aliases/groups/flattened groups, runs access conditions, then invokes resolved command.

    • interface:handle(entity?: any): commands.invoker
      Shortcut for manager:handle(interface, entity).

    • interface:condition(invoker, command, next)
      Global interface access hook.
      Default next(true).

    • interface:failure(invoker, command, err)
      Called for user-facing command failure reasons.

    • interface:error(invoker, command, critical)
      Called for internal/traceback failures.

    Required Overrides¶

    • interface:reply(invoker, command, ...)
    • interface:rreply(invoker, command, ...)
    • interface:message(invoker, command, targets, ...)
    • interface:rmessage(invoker, command, targets, ...)
    • interface:username(invoker): string
    • interface:identifier(invoker): string
    • interface:groups(invoker, cb)
    • interface:primary(invoker, cb)
    • interface:secondary(invoker, cb)
    • interface:can(invoker, other, permissions: string[], cb)
    • interface:has(invoker, permissions: string[], cb)
      invoker:throw(...) also expects your interface to implement throw(...).

    Invoker¶

    Runtime execution context passed to command callbacks.

    • invoker:type(): string
    • invoker:serverless(): boolean
    • invoker:setsilent(state: boolean)
    • invoker:issilent(): boolean
    • invoker:username(): string
    • invoker:identifier(): string
    • invoker:phrase(...): string
    • invoker:throw(...)
    • invoker:reply(...)
    • invoker:rreply(...)
    • invoker:message(...)
    • invoker:rmessage(...)
    • invoker:groups(cb)
    • invoker:primary(cb)
    • invoker:secondary(cb)
    • invoker:can(other, permissions: string | string[], cb)
    • invoker:has(permissions: string | string[], cb)

    Argument Objects¶

    Created by commands:argument(...).

    • argument.name: string
    • argument.callback(command, argument, invoker, flags, input: string[], index: number): boolean, any?, number?
      Expected return contract: true, parsedValue, consumedOffset? on success;
      false, userError on parse/validation failure.
      Thrown errors become internal failures (functional.argument.internal).

    Argument utilities: - argument:destructor() - argument:phrase(key, ...): string

    Built-In Arguments¶

    Registered by commands:baseline().

    • number
      tonumber parse with flags.min, flags.max, flags.round, flags.default, flags.optional.

    • string
      Supports quoted multi-word parsing; optional/default behavior.

    • select
      Single value from flags.options.

    • multi
      Comma-separated values from flags.options; supports flags.min/flags.max.

    • boolean
      Truthy only for "1" or "true" (string forms); otherwise false/default/optional path.

    • color
      Accepts R,G,B[,A] or hex #RRGGBB[AA].

    • vector
      Accepts X,Y,Z.

    • angle
      Accepts P,Y,R.

    • time
      Accepts absolute seconds or tokenized units (y, mo, w, d, h, m, s).
      Helper exposed as commands.to_seconds(value).

    • player
      Supports selector expressions with RPN operators +, -, !, parentheses.
      Supports prefixes: @ aimed player, ^ self, * all, $ steam id lookup, # usergroup, & radius, ? random count.
      Flags include single, limit, filter, default, optional.

    • entity
      Same expression model as player, but for entities.
      Prefixes: @ aimed entity, ^ self entity, * all entities, # class find, $ entity index, & radius.

    • steam
      Accepts SteamID, SteamID64, or profile URL.
      ^ resolves invoker steamid64.

    Picker extension¶

    • commands.arguments.player:add_picker(prefix: string, cb)
    • commands.arguments.player:get_picker(prefix: string)
    • commands.arguments.player:remove_picker(prefix: string)
    • commands.arguments.entity:add_picker(prefix: string, cb)
    • commands.arguments.entity:get_picker(prefix: string)
    • commands.arguments.entity:remove_picker(prefix: string)

    sRPN Parser¶

    Set-expression engine used by player/entity arguments.

    • commands.sRPN:tokenize(text: string): token[]
    • commands.sRPN:parse(tokens: token[]): token[] | false, string
    • commands.sRPN:eval(rpn: token[], ...): table | false, string
      identifier(...) and iterator(...) are expected to be overridden by concrete engines.
